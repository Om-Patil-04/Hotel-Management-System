================================================================================
                            DATA FLOW SEQUENCE
================================================================================

REQUEST FLOW:
-------------
1. User Request
   └── Browser sends HTTPS request to Cloud Run URL

2. Load Balancer
   └── Cloud Run routes request to available container instance

3. Container Startup (if cold start)
   ├── Gunicorn starts with --preload
   ├── Flask app initializes
   ├── PredictPipeline.__init__() executes
   ├── Check if model exists at /app/models/best_model/model.pkl
   ├── If not exists: Download from gs://hotel-management-models/best_model/
   ├── Load model with joblib.load()
   └── Ready to serve requests

4. Request Processing
   ├── Gunicorn receives request
   ├── Routes to Flask application
   ├── Flask calls appropriate route handler
   ├── InputPreprocessor validates and encodes input
   ├── PredictPipeline.predict() processes data
   ├── Model generates prediction and probability
   └── Response returned to user

5. Logging
   └── Prediction logged to /app/logs/predictions/YYYYMMDD.jsonl


PREDICTION FLOW:
----------------
User Input (Web Form or API)
    ↓
InputPreprocessor.validate_and_encode()
    ├── lead_time (float, ≥0)
    ├── no_of_special_requests (float, 0-10)
    ├── avg_price_per_room (float, ≥0)
    ├── arrival_month (int, 1-12)
    ├── arrival_date (int, 1-31)
    ├── no_of_week_nights (float, ≥0)
    ├── no_of_weekend_nights (float, ≥0)
    ├── type_of_meal_plan (categorical → float)
    ├── market_segment_type (categorical → float)
    └── room_type_reserved (categorical → float)
    ↓
Encoded Feature Vector (10 features)
    ↓
StandardScaler.transform() (if scaler exists)
    ↓
RandomForestClassifier.predict_proba()
    ↓
Apply Threshold (0.652)
    ↓
Return Prediction
    ├── prediction: "Not Canceled" or "Canceled"
    ├── prediction_label: 1 or 0
    ├── probability: float (0.0 to 1.0)
    ├── probability_percent: float (0 to 100)
    ├── threshold: 0.6527746612570925
    └── model_name: "RandomForest"


================================================================================
                          DEPLOYMENT WORKFLOW
================================================================================

STEP 1: CODE COMMIT
--------------------
Developer → git add . → git commit -m "message" → git push origin main
    ↓
GitHub Repository Updated
    ↓
Webhook Triggered to Jenkins


STEP 2: JENKINS PIPELINE EXECUTION
-----------------------------------
Jenkins receives webhook
    ↓
Execute Jenkinsfile:
    Stage 1: Checkout
        └── Clone repository from GitHub
    
    Stage 2: Build and Deploy
        ├── Authenticate to GCP using service account
        ├── Trigger gcloud builds submit
        └── Execute cloudbuild.yaml
    
    Stage 3: Verify
        └── Check deployment status


STEP 3: CLOUD BUILD EXECUTION
------------------------------
Cloud Build receives trigger
    ↓
Execute cloudbuild.yaml:
    Step 1: Build Docker Image
        └── docker build -t IMAGE_NAME .
    
    Step 2: Push to Artifact Registry
        └── docker push asia-south1-docker.pkg.dev/PROJECT/REPO/IMAGE:TAG
    
    Step 3: Deploy to Cloud Run
        └── gcloud run deploy hotel-management-system \
                --image IMAGE_NAME \
                --region asia-south1 \
                --platform managed \
                --allow-unauthenticated


STEP 4: CLOUD RUN DEPLOYMENT
-----------------------------
Cloud Run receives deployment request
    ↓
Create new revision
    ├── Pull image from Artifact Registry
    ├── Create container instances
    ├── Run health checks
    └── Route traffic to new revision (100%)
    ↓
Old revision scaled down
    ↓
Deployment complete


STEP 5: CONTAINER INITIALIZATION
---------------------------------
Container starts
    ↓
Execute CMD from Dockerfile:
    gunicorn --bind 0.0.0.0:8080 \
             --workers 1 \
             --timeout 120 \
             --preload \
             --access-logfile - \
             application:app
    ↓
Gunicorn with --preload:
    ├── Import application module
    ├── Execute: pipeline = PredictPipeline()
    ├── PredictPipeline.__init__() runs
    ├── Check: os.path.exists(MODEL_OUTPUT_PATH)
    ├── If False: _download_model_from_gcs()
    │   ├── Connect to GCS
    │   ├── Download model.pkl (135.6 MB)
    │   └── Save to /app/models/best_model/model.pkl
    ├── Load model: joblib.load(MODEL_OUTPUT_PATH)
    ├── Extract model components
    └── Print: "Loaded model: RandomForest"
    ↓
Fork worker processes
    ↓
Workers inherit loaded model (memory shared)
    ↓
Container ready to serve requests

================================================================================
                    TROUBLESHOOTING GUIDE
================================================================================

ISSUE: Service Unavailable
---------------------------
1. Check Cloud Run logs for errors
2. Verify container starts successfully
3. Check health endpoint: curl SERVICE_URL/health
4. Verify model downloaded from GCS
5. Check timeout settings


ISSUE: Model Not Loading
-------------------------
1. Verify GCS bucket exists
2. Check service account has Storage Object Viewer role
3. Verify model path: gs://hotel-management-models/best_model/model.pkl
4. Check container has internet access
5. Increase timeout if download is slow


ISSUE: Prediction Errors
-------------------------
1. Validate input format matches schema
2. Check all required fields are provided
3. Verify categorical values are in allowed list
4. Check numeric ranges
5. Review application logs


ISSUE: Build Failures
----------------------
1. Check Dockerfile syntax
2. Verify all dependencies in requirements.txt
3. Check Cloud Build service account permissions
4. Review Cloud Build logs
5. Verify Artifact Registry repository exists


ISSUE: Deployment Failures
---------------------------
1. Check Cloud Run service exists
2. Verify region matches
3. Check image exists in Artifact Registry
4. Verify Jenkins service account permissions
5. Review Cloud Build logs
